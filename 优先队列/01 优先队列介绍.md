## 优先队列

优先队列是一种 **抽象数据类型（ADT）** ，支持插入元素，并按照元素的优先级选择要删除的元素

与栈和普通队列不同，优先级队列不按照元素的插入顺序决定删除哪个元素，而是按照优先级选择删除元素

---
## 与其他数据结构的区别

| 数据结构                 | 删除规则       |
| -------------------- | ---------- |
| 栈（Stack）             | 后进先出（LIFO） |
| 队列（Queue）            | 先进先出（FIFO） |
| 优先队列（Priority Queue） | 按照优先级取出元素  |

---
## 优先队列的类型

- 最大优先队列（Max Priority Queue）：每次删除最大元素
- 最小优先队列（Min Priority Queue）：每次删除最小元素

---
## 优先队列的两种简单实现

**无序数组** 

元素按照插入顺序存储，不要求数组有序

- **插入：** 直接将新元素放到数组末尾
- **删除最大值：** 遍历整个数组，找到最大元素并删除

> **优点：** 插入简单、速度快
> **缺点：** 删除最大值需要遍历所有元素

---
**有序数组** 

始终保持数组中的元素按照大小顺序排列

- **插入：** 找到合适的位置，并移动其他元素
- **删除最大值：** 直接删除数组末尾的元素

> **优点：** 删除最大值简单、速度快
> **缺点：** 插入时可能需要移动大量元素

---
**两种实现的复杂度** 

设 n 为队列中的元素数量

| 操作    | 无序数组   | 有序数组   |
| ----- | ------ | ------ |
| 插入    | $O(1)$ | $O(n)$ |
| 查看最大值 | $O(n)$ | $O(1)$ |
| 删除最大值 | $O(n)$ | $O(1)$ |

效果都不算好，所以，就要引出 **二叉堆** 了

---
无序数组和有序数组各有优缺点：

- 无序数组插入快，但删除最大值慢
- 有序数组删除最大值快，但插入慢

当插入和删除操作频繁交替执行时，两种实现都存在明显不足

因此，需要一种更高效的数据结构，让插入和删除最大值都能在较短时间内完成

二叉堆（Binary Heap）不要求所有元素整体有序，而是维护特定的父子节点顺序关系，从而提高操作效率

| 操作    | 时间复杂度     |
| ----- | --------- |
| 插入    | $O(logn)$ |
| 查看最大值 | $O(1)$    |
| 删除最大值 | $O(logn)$ |

- 最大堆常用于实现最大优先队列
- 最小堆常用于实现最小优先队列
