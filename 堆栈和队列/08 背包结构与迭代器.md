## 迭代器(Iterator)

**迭代器** 是用来遍历数据结构的一种 **工具** 

目前我们已经实现了数据结构的 **存储** 、**删除**  操作，并且通过 **泛型** 支持了多种类型

但是，如果想查看数据结构中的所有元素，直接使用 出队、出栈 等操作会破坏原有数据；如果直接访问内部结构，又会暴露数据结构的实现

因此，引入 **Inerator（迭代器）** ，它可以在不破坏数据的情况下遍历数据结构，同时隐藏内部实现
### 代码
```cpp
//ResizingArrayQueue.h
#include <utility>
#include <stdexcept>

template <typename T> //作用域为后面紧挨着的第一个函数

class ResizingArrayQueue
{
private:
	//迭代器
    class ArrayIterator
    {
    public:
        ArrayIterator(T* q, int front, int size, int capacity)
        : q(q), front(front), size(size), capacity(capacity) {}
        ~ArrayIterator() = default;
        
        bool hasNext() const { return size > 0; }
        T next()
        {
            if(!hasNext())
            {
                throw std::out_of_range("No more element");
            }
            T item = q[(front + i++) % capacity];
            size--;
            return item; 
        }


    private:
        T* q;
        int front = 0;
        int size = 0;
        int capacity = 0;
        int i = 0;
    };
public:
    ResizingArrayQueue() : q(new T[1]), front(0), rear(0), capacity(1), size(0)
    {
    }
    ~ResizingArrayQueue()
    {
        delete[] q;
    }

    ResizingArrayQueue(const ResizingArrayQueue&) = delete;
    ResizingArrayQueue& operator=(const ResizingArrayQueue&) = delete;

    bool isEmpty()
    {
        return size == 0;
    }

    void enqueue(T item)
    {
        if(size == capacity)
        {
            resize(2 * capacity);
        }
        q[rear] = std::move(item);
        rear = (rear + 1) % capacity;
        size++;
    }

    T dequeue()
    {
        if(isEmpty())
        {
            throw std::underflow_error("Dequeue from empty queue");
        }
        T item = std::move(q[front]);
        front = (front + 1) % capacity;
        size--;

        if(size > 0 && size == capacity / 4)
        {
            resize(capacity / 2);
        }
        return item;
    }
    
	//获得迭代器实例
    ArrayIterator iterator()
    { return ArrayIterator(q, front, size, capacity); }

private:
    T* q;
    int front = 0;
    int rear = 0;
    int capacity = 0;
    int size = 0;

    void resize(int newCapacity)
    {
        T* newData = new T[newCapacity];
        
        for(int i = 0; i < size; i++)
        {
            newData[i] = std::move(q[(front + i) % capacity]);
        }

        delete[] q;

        q = newData;
        capacity = newCapacity;
        front = 0;
        rear = size;
    }
};
```

```cpp
//main.cpp
#include <iostream>
#include <string>
#include "ResizingArrayQueue.h"

int main(void)
{
    ResizingArrayQueue<std::string> quStr;
    std::string str;

    
    while(std::cin >> str)
    {
        if(str == "-")
        {
            std::cout << quStr.dequeue() << std::endl;
        }
        else if(str == "&")
        {
	        //使用迭代器
            auto it = quStr.iterator();
            while(it.hasNext())
            {
                std::cout << it.next() << " ";
            }
            std::cout << std::endl;
        }
        else
        {
            quStr.enqueue(str);
        }

    }

    return 0;
}
```

这里用了泛型化的数组实现队列作为例子，其他的也是这样

## 背包(Bag)结构
### 前言
Bag结构是一种只负责存储元素的容器，它不关心元素之间的顺序，也不进行去重操作。
与Set不同，Bag 允许存储重复元素
Bag 虽然不关心顺序，但是 **它内部仍然有一个存储顺序** 
Bag一般不考虑数据的删除，它只考虑存储
### 代码
```cpp
//Bag.h
#include <utility>
#include <stdexcept>

template <typename T>
class Bag
{
private:
    struct Node
    {
        T item;
        Node* next;

        Node() : item{}, next(nullptr) {}
        Node(T item) : item(std::move(item)), next(nullptr) {}
    };
    
    Node* first = nullptr;
    int sz = 0;

    class BagIterator
    {
    private:
        Node* current = nullptr;
    public:
        BagIterator(Node* first) : current(first) {}
        bool hasNext() const { return current != nullptr; }
        T next()
        {
            if(!hasNext())
            {
                throw std::out_of_range("No more element");
            }
            T item = current->item;
            current = current->next;
            return item;
        }
    };
public:
    Bag() = default;
    ~Bag()
    {
        while(first != nullptr)
        {
            Node* temp = first;
            first = first->next;
            delete temp;
        }
    }

    Bag(const Bag&) = delete;
    Bag& operator=(const Bag&) = delete;

    void add(T item)
    {
        Node* oldFirst = first;
        first = new Node(std::move(item));
        first->next = oldFirst;
        sz++;
    }
    
    int size() const { return sz; }

    BagIterator iterator() { return BagIterator(first); }
};
```

```cpp
//main.cpp
#include <iostream>
#include <string>
#include "Bag.h"

int main(void)
{
    Bag<std::string> bag;
    std::string str;

    while(std::cin >> str)
    {
        if(str == "&")
        {
            auto it = bag.iterator();
            while(it.hasNext())
            {
                std::cout << it.next() << " ";
            }
            std::cout << std::endl;
        }
        else
        {
            bag.add(str);
        }
    }

    return 0;
}
```
