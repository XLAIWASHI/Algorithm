## 前言
之前我们实现的 栈 和 队列 都是只能存储字符串；那么如果我们想要存储多个类型，我们可以使用 **泛型** 

**泛型** 顾名思义，使用泛型，可以只实现一次，根据不同类型生成对应版本，避免为每一种类型重复编写代码

## 代码
具体实现和前面的一样，所以这里就只实现一个队列的
```cpp
//ResizingArrayQueue.h
#include <utility>
#include <stdexcept>

template <typename T> //作用域为后面紧挨着的第一个类

class ResizingArrayQueue
{
public:
    ResizingArrayQueue() : q(new T[1]), front(0), rear(0), capacity(1), size(0)
    {

    }
    ~ResizingArrayQueue()
    {
        delete[] q;
    }

    ResizingArrayQueue(const ResizingArrayQueue&) = delete;
    ResizingArrayQueue& operator=(const ResizingArrayQueue&) = delete;

    bool isEmpty()
    {
        return size == 0;
    }

    void enqueue(T item)
    {
        if(size == capacity)
        {
            resize(2 * capacity);
        }
        q[rear] = std::move(item);
        rear = (rear + 1) % capacity;
        size++;
    }

    T dequeue()
    {
        if(isEmpty())
        {
            throw std::underflow_error("Dequeue from empty queue");
        }
        T item = std::move(q[front]);
        front = (front + 1) % capacity;
        size--;

        if(size > 0 && size == capacity / 4)
        {
            resize(capacity / 2);
        }
        return item;
    }

private:
    T* q;
    int front = 0;
    int rear = 0;
    int capacity = 0;
    int size = 0;

    void resize(int newCapacity)
    {
        T* newData = new T[newCapacity];
        
        for(int i = 0; i < size; i++)
        {
            newData[i] = std::move(q[(front + i) % capacity]);
        }

        delete[] q;

        q = newData;
        capacity = newCapacity;
        front = 0;
        rear = size;
    }
};
```

```cpp
//main.cpp
#include <iostream>
#include <string>
#include "ResizingArrayQueue.h"

int main(void)
{
    ResizingArrayQueue<std::string> quStr; //实现的时候给定一个需要的类型
    std::string str;
    
    while(std::cin >> str)
    {
        if(str == "-")
        {
            std::cout << quStr.dequeue() << std::endl;
        }
        else
        {
            quStr.enqueue(str);
        }
    }

    return 0;
}
```

## 注
这个实现，一定要 **同一个文件** 中实现，一般都在 `.h` 文件中；

**首先需要明确** ，`.h` 文件不单独编译，她随着 `cpp` 文件一起编译；

---
**普通代码流程** 

假设，存在
```
main.cpp
stack.h
stack.cpp
```
main.cpp 中引入了 stack.h

- 编译时，`stack.h` 会通过 `#include` 展开到 `main.cpp` 中，一起形成翻译单元；`stack.cpp` 则独立编译
- 链接阶段，链接器根据目标文件中的符号，将 main 需要的函数和 stack.cpp 编译生成的实现连接起来

---
**模板代码流程** 

假设，存在
```
main.cpp
stack.h
stack.cpp
```
main.cpp 中引入了 stack.h

- 编译时，`stack.h` 会通过 `#include` 展开到 `main.cpp` 中，一起形成翻译单元；`stack.cpp` 则独立编译
- `stack.cpp` 中，编译器只看模板定义，不清楚未来需要哪些具体类型，因此不会生成对应代码
- 当 `main.cpp` 使用：
```cpp
ResizingArrayQueue<std::string> quStr;
```
时，编译器知道需要 `std::string` 版本，但是没有模板的实现，无法实例化对应的代码

> **就像带着答案出题一样，先确定类型，然后编译器根据模板定义生成对应类型的代码**
