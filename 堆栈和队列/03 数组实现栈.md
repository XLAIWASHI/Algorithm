```cpp
//FixedCapacityStackOfStrings.h
#include <string>

class FixedCapacityStackOfStrings
{
public:
    FixedCapacityStackOfStrings(int capacity);
    ~FixedCapacityStackOfStrings();

    //禁止拷贝
    FixedCapacityStackOfStrings(const FixedCapacityStackOfStrings&) = delete;
    FixedCapacityStackOfStrings& operator=(const FixedCapacityStackOfStrings&) = delete;

    bool isEmpty();
    void push(std::string item);
    std::string pop();
private:
    std::string* s;
    int capacity = 0;
    int size = 0;
};
```

```cpp
//FixedCapacityStackOfStrings.cpp
#include "FixedCapacityStackOfStrings.h"
#include <stdexcept>
#include <utility>

FixedCapacityStackOfStrings::FixedCapacityStackOfStrings(int capacity)
    : s(new std::string[capacity]), capacity(capacity), size(0)
{
    if(capacity <= 0) throw std::invalid_argument("Capacity must be positive");
}

FixedCapacityStackOfStrings::~FixedCapacityStackOfStrings()
{
    delete[] s; //释放数组内存，带中括号
}

bool FixedCapacityStackOfStrings::isEmpty()
{
    return size == 0;
}

void FixedCapacityStackOfStrings::push(std::string item)
{
    if(size >= capacity)
    {
        throw std::overflow_error("Push to full stack");
    }
    s[size++] = std::move(item);
}

std::string FixedCapacityStackOfStrings::pop()
{
    if(isEmpty())
    {
        throw std::underflow_error("Pop from empty stack");
    }
    return std::move(s[--size]);
}
```
但是，我们这个实现，数组的大小是通过外部传入的，这样不好，所以我们接下来要实现动态调整数组大小

## 数组实现-动态调整数组大小
### 思路
#### 方案一：线性扩容(不推荐)
为了解决 **容量固定** 的问题，我们可以很简单的想到 **当栈满时，自动扩容**

- **简单做法** 当 元素个数 == 当前容量 时，新建一个比原来 **大 1 个元素** 的数组，把旧数据复制过去，出栈时，再减去这个位置

这个比较符合直觉，每次只要多加 1 个位置，刚刚好够用，不浪费

---
**但这样做存在严重的性能问题：**

- 如果数组的大小是 n - 1, 那么此时需要的代价就是 n
- 如果数组的大小是 n - 2, 那么此时需要的代价就是 n - 1
- 那么最终的总代价就是 (1 + 2 + ... + n - 1 + n) ~ $n^2/2$ 

> **最终时间复杂度：** $O(n^2)$ 
#### 方案二：反复倍增
为了降低整体时间复杂度，核心优化思路是： **尽量减少扩容的次数** 

- **做法** 当 元素个数 == 当前容量 时，不再增加 1 个位置，而是直接将 **容量翻倍** ，将旧数据整体搬移至新数组
---
**分析**
这里用到一个分析法，叫做 **均摊分析法**

假设当前栈容量为 n ，需要执行 n + 1 次入栈

- 前 n 次直接存入，代价为 n
- 第 n + 1 次触发扩容，容量翻倍，搬运旧 n 个元素，（代价为n），再存入新元素（代价为1）
- 那么总代价为 （2n + 1）

那么将总代价（2n + 1）均摊到（n + 1）次操作，则， **每次单次操作约等于 2 次常数操作**
