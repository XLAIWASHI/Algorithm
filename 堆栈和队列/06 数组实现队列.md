## 数组实现-动态调整数组大小
## 思路

实现方法和栈是一样的，都是用到 **反复倍增** 的策略

- **入队做法** 当 元素个数 == 当前容量 时，将 **容量翻倍** ，并将旧数据整体搬移至新数组
- **出队做法** 当 元素个数 降至 当前容量的 1/4 时，触发缩容，将容量减半
---
**enqueue均摊分析** 

假设当前队列容量为 n，需要执行 n + 1 次入队

- 前 n 次直接存入，代价为 n
- 第 n + 1 次触发扩容，容量翻倍，搬运旧 n 个元素，（代价为n），再存入新元素（代价为1）
- 那么总代价为（2n + 1）

那么将总代价（2n + 1）均摊到（n + 1）次操作，则， **每次单次操作约等于 2 次常数操作** 
即
> **均摊时间复杂度为：** $O(1)$ 

---
**dequeue均摊分析** 

为了充分利用内存空间，我们使用了 **循环队列** 的方法

假设当前队列容量为 4n，元素个数 2n，需要执行 n 次出队

- 前 n - 1 次直接出，代价为 n - 1
- 第 n 次触发缩容，容量减半，搬运旧 n 个元素，（代价为n）
- 那么总代价为 （ 2n - 1）

那么将总代价（2n - 1）均摊到 n 次操作，则，**每次单次操作约等于 2 次常数操作** 
即
> **均摊时间复杂度为：** $O(1)$ 

---
**实现与复杂度分析**

复杂度分析应基于具体实现，如

- 扩容通常发生在插入前，因为需要保证有空间存放新元素
- 缩容通常发生在删除后，因为需要根据删除后的元素数量判断空间是否过多

因此：
- 扩容分析可能是第 n+1 次操作触发
- 缩容分析可能是第 n 次操作触发

两者虽形式不同，但均摊复杂度仍为 $O(1)$ 
## 代码
```cpp
//ResizingArrayQueueOfStrings.h
#include <string>
#include <utility>

class ResizingArrayQueueOfStrings
{
public:
    ResizingArrayQueueOfStrings();
    ~ResizingArrayQueueOfStrings();

    //禁止拷贝
    ResizingArrayQueueOfStrings(const ResizingArrayQueueOfStrings&) = delete;
    ResizingArrayQueueOfStrings& operator=(const ResizingArrayQueueOfStrings&) = delete;

    bool isEmpty();
    void enqueue(std::string item);
    std::string dequeue();
private:
    void resize(int newCapacity);
    std::string* q;
    int front = 0; //队头位置
    int rear = 0; //下一个插入位置
    int capacity = 0; //数组容量
    int size = 0; //当前元素个数
};
```

```cpp
//ResizingArrayQueueOfStrings.cpp
#include "ResizingArrayQueueOfStrings.h"
#include <stdexcept>

ResizingArrayQueueOfStrings::ResizingArrayQueueOfStrings()
    : q(new std::string[1]), size(0), capacity(1), front(0), rear(0)
{
}

ResizingArrayQueueOfStrings::~ResizingArrayQueueOfStrings()
{
    delete[] q;
}

void ResizingArrayQueueOfStrings::enqueue(std::string item)
{
    if(size == capacity)
    {
        resize(2 * capacity);
    }
    q[rear] = std::move(item);
    rear = (rear + 1) % capacity; //使用循环数组，充分利用空间
    size++;
}

std::string ResizingArrayQueueOfStrings::dequeue()
{
    if(isEmpty())
    {
        throw std::underflow_error("Dequeue from empty queue");
    }

    std::string item = std::move(q[front]);
    front = (front + 1) % capacity;
    size--;

    if(size > 0 && size == capacity / 4)
    {
        resize(capacity / 2);
    }
    return item;
}

void ResizingArrayQueueOfStrings::resize(int newCapacity)
{
    std::string* newData = new std::string[newCapacity];

    for(int i = 0; i < size; i++)
    {
        newData[i] = std::move(q[(front + i) % capacity]);
    }
    
    delete[] q;

    q = newData;
    capacity = newCapacity;
    front = 0;
    rear = size;
}

bool ResizingArrayQueueOfStrings::isEmpty()
{
    return size == 0;
}
```
