## 栈
一种数据结构，其特点为 **先入后出 LIFO(Last In, First Out)** 

## 实现
### 链表实现
```cpp
//LinkedStackOfStrings类
#include <string>

struct Node
{
    std::string item;
    Node* next;

    Node() : item{}, next(nullptr) {}
    Node(std::string item) : item(item), next(nullptr) {}
};

class LinkedStackOfStrings
{
public:
    bool isEmpty();
    void push(std::string item);
    std::string pop();
private:
    Node* head = nullptr; //作为栈顶
};
```

```cpp
//LinkedStackOfStrings类实现
#include "LinkedStackOfStrings.h"
#include <stdexcept>

bool LinkedStackOfStrings::isEmpty()
{
    return head == nullptr;
}

void LinkedStackOfStrings::push(std::string item)
{
    Node* newNode = new Node(item);
    newNode->next = head;
    head = newNode;
}

std::string LinkedStackOfStrings::pop()
{
    if (head == nullptr)
    {
        throw std::runtime_error("LinkedStackOfStrings::pop(): Stack is empty");
    }
    Node* next = head->next;
    std::string str = head->item;
    delete head;
    head = next;
    return str;
}
```
