## 前言
在正式开始排序算法前，我们需要先了解一些设计思想

假设现在有一个排序算法的开发者，他希望自己的算法能够被不同的用户使用：

- 不同的用户需要排序的类型不同
- 使用的类型不光有基本类型和标准库类型，还有用户自定义的类型
- 即使是同样的类型，用户的比较规则也可能不同

那么问题是：

> **如何设计一个排序算法，使她不需要关心具体的数据类型，也不需要提前知道用户的排序规则，却依然可以满足不同用户的需求** 

为了解决这个问题，我们需要引入两个重要思想：

1.**泛型思想(Template)** 
- 解决类型变化的问题，使同一份算法能够处理不同类型的数据
- 可以处理不同类型的数据

2.**回调机制(Callback)** 
- 解决不同排序规则的问题
- 允许用户将自己的比较规则传递给算法，由算法在需要比较时主动调用该规则

## 泛型思想
假设，我们需要交换两个变量
```cpp
void swap(int& a, int& b)
{
    int temp = a;
    a = b;
    b = temp;
}
```
这个函数只能交换 `int` 
如果需要其他类型，只能重写；导致写很多代码
但是，用泛型就可以解决这个问题

```cpp
template<typename T>
void swap(T& a, T& b)
{
    T temp = a;
    a = b;
    b = temp;
}
```
这里的 `T` 只是一个占位符
使用时
```cpp
int a, b;
swap(a, b);
```
编译器会 **根据调用时提供的类型，对模板进行实例化，生成对应版本的函数** 

**注：**
如果是函数的话，编译器可以根据参数类型，推导出需要的类型；这个过程叫作： **模板参数推导** 
如果是类模板的话，就不可以，比如
```cpp
template<typename T>
class ResizingArrayQueue
{
private:
    T* array;
    int size;
};
```
声明
```cpp
ResizingArrayQueue queue;
```
编译器不知道当前需要的是什么类型
所以
```cpp
ResizingArrayQueue<int> q;
```
类模板的话需要给定一个类型

**总结** 
> **在排序算法中，泛型让算法不依赖具体的数据类型**
