## 凸包(Convex Hull)

![image-1786627454321.png](../../assets/05%20凸包%20-%20排序应用/image-1786627454321.png)

- 凸包是包含所有点的最小凸状集合
- 凸包是最小的能圈起所有点的凸多边形
- 凸包是最小的包含所有点，并且顶点也都数这个集合的凸多边形

## 凸包的性质

![image-1786640346341.png](../../assets/05%20凸包%20-%20排序应用/image-1786640346341.png)

选取 y 坐标最低的点 p 作为参考点

从 p 出发，以 x 轴正方向作 0° ，逆时针观察其他点

- 其他点相对于 p 的极角处于 `0° ~ 180°` 
- 沿逆时针方向，极角逐渐增大
- 因此可以按照极角从小到大的顺序对点进行排序

这样，我们就可以从 p 开始，按照固定的逆时针方向依次扫描这些点

---
**极角** 

极角表示一个点相对于参考点的方向

- 选择一个参考点 p ，以 x 轴正方向作为 0° 
- 从 p 出发逆时针旋转到目标点 a 
- 旋转过的角度就是 a 相对于 p 的极角

在凸包中，通常选择 y 坐标最低的点作为参考点，因此其他点的极角范围为：`0° ~ 180°` 

---
## 葛立恒扫描(Graham Scan)

**基本思路** 

将所有点按照极角排序后，从参考点开始按照逆时针方向依次扫描

在扫描过程中，维护一个当前的凸包。如果加入新点后，使最后三个点不再保持逆时针方向，那么中间的点一定不属于凸包，需要将其移除

---
**流程** 

- 对所有点的 y 坐标排序，找到最小的作为 **参考点** 
- 对所有点相对于参考点的 **极角** 排序
- 按照极角从小到大的顺序，依次链接每个点
- 如果当前点 与 前两个点不能构成 **逆时针** 
- 断开上一条连接，移除中间点，继续检查
- 如果满足逆时针，则继续连接下一个点

---
**判断是否逆时针** 

**叉积：** 

经典的叉积是 **三维向量** 之间的运算

对于三个点 `a, b, c` ，先构造两个向量：

$$
\vec{ab} = b - a
$$
$$
\vec{ac} = c - a
$$

将二维向量看作 `z = 0` 的三维向量：

$$
\vec{ab} = (x_1, y_1, 0)
$$
$$
\vec{ac} = (x_2, y_2, 0)
$$


计算叉积：

$$
\vec{ab} \times \vec{ac}
$$

叉积得到的向量 **垂直于两个向量所在的平面** 

由于两个向量都在 `xy` 平面上，因此叉积结果只会沿 `z` 轴：

$$
\vec{ab} \times \vec{ac} = (0, 0, z)
$$

根据 **右手法则：** 

- `z > 0` ：指向 `+z` ，`a -> b -> c` 为 **逆时针** 
- `z < 0` ：指向 `-z` ，`a -> b -> c` 为 **顺时针** 
- `z = 0` ：三个点 **共线** 

其中 `z` 分量为：

$$
z = (b_x - a_x)(c_y - a_y) - (b_y - a_y)(c_x - a_x)
$$

因此，在二维计算几何中，可以直接通过这个值的正负判断三个点的转向

**葛立恒扫描正是利用这个性质，判断当前三个点是否持逆时针，从而决定是否移除中间点** 

---
### 计算过程

有：

$$
\vec{ab} = (x_1, y_1, 0)
$$
$$
\vec{ac} = (x_2, y_2, 0)
$$

那么：

$$
\vec{ab} \times \vec{ac}
=
\begin{vmatrix}
i & j & k \\
a_x & a_y & 0 \\
b_x & b_y & 0
\end{vmatrix}
$$

按第一行展开：

$$
=
i
\begin{vmatrix}
a_y & 0 \\
b_y & 0
\end{vmatrix}
-
j
\begin{vmatrix}
a_x & 0 \\
b_y & 0
\end{vmatrix}
+
k
\begin{vmatrix}
a_x & a_y \\
b_x & b_y
\end{vmatrix}
$$

前两个行列式都是0:

$$
= 0i - 0j + (a_x b_y - a_y b_x)k
$$

所以最终：

$$
(0, 0, a_x b_y - a_y b_x)
$$

也就是说，**因为两个向量的 z 坐标都是 0 ， 所以叉积的 x，y 分量都变成 0 ，只剩下 z 分来给你

所以最后只需要计算 z 分量：

$$
a_x b_y - a_y b_x
$$

## 代码

```cpp
#include <iostream>
#include <vector>
#include <stack>
#include <algorithm>
#include <cmath>

struct Point2D
{
    int x;
    int y;

    Point2D(int x, int y) : x(x), y(y) {}
};

int ccw(const Point2D& a, const Point2D& b, const Point2D& c)
{
    int z = (b.x - a.x) * (c.y - a.y) - (b.y - a.y) * (c.x - a.x);
    if(z < 0)
    {
        return -1;
    }
    else if(z > 0)
    {
        return 1;
    }
    else
    {
        return 0;
    }
}

std::stack<Point2D> GrahamScan(std::vector<Point2D>& points)
{
    std::sort(points.begin(), points.end(), [](const Point2D& a, const Point2D& b)
    {
        if(a.y != b.y)
            return a.y < b.y;
        return a.x < b.x;
    });
    Point2D p0 = points[0];
    std::sort(points.begin() + 1, points.end(), [p0](const Point2D& a, const Point2D& b)
    {
        double angleA = std::atan2(a.y - p0.y, a.x - p0.x);
        double angleB = std::atan2(b.y - p0.y, b.x - p0.x);
        return angleA < angleB;
    });

    std::stack<Point2D> sk;
    sk.push(points[0]);
    sk.push(points[1]);

    for(int i = 2; i < points.size(); i++)
    {
        Point2D top = sk.top();
        sk.pop();

        while(sk.size() >= 2 && ccw(sk.top(), top, points[i]) <= 0) //顺时针或共线
        {
            top = sk.top();
            sk.pop();
        }
        sk.push(top);
        sk.push(points[i]);
    }

    return sk;
}

int main(void)
{
    std::vector<Point2D> points = {
        Point2D(0, 0),
        Point2D(2, 1),
        Point2D(4, 0),
        Point2D(5, 3),
        Point2D(3, 5),
        Point2D(1, 4),
        Point2D(2, 2),
        Point2D(3, 2)
    };

    std::stack<Point2D> sk = GrahamScan(points);

    while(!sk.empty())
    {
        std::cout << "(" << sk.top().x << ", " << sk.top().y << ")" << " ";
        sk.pop();
    }

    return 0;
}
```
