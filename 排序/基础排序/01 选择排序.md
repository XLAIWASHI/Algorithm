## 排序思路

**选择排序** 是一个非常简单的排序，他的思路是：

- 在第 i 次迭代中，在未排序区间 `[i, n)` 中找到最小元素，将其与第 i 个元素交换

## 循环不变性 (Loop Invariant)

**定义**
> 在循环执行过程中，某个条件始终保持成立，这个条件称为 **循环不变性** 

它用于证明：

- 算法为什么正确
- 每一轮循环完成了什么
---
**对于选择排序** 

每次循环开始时：

- `i` 左边的元素 `[0, i)` 已经排好序
- 这些元素是当前数组中最小的 `i` 元素
- 后续循环不会再访问并修改 `[0, i)` 区间,因此该区间保持确定

因此每轮循环找到剩余部分 `[i, n)` 中的最小元素，并放到位置 `i` ，使循环不变性继续成立

## 代码

```cpp
#include <iostream>
#include <vector>

template <typename T>
void mySwap(std::vector<T>& arr, int i, int j)
{
    T temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
}

template <typename T, typename Compare>
void selectSort(std::vector<T>& arr, Compare cmp)
{
    int n = arr.size();
    for(int i = 0; i < n; i++)
    {
        int min = i;
        for(int j = i + 1; j < n; j++)
        {
            if(cmp(arr[j], arr[min]))
            {
                min = j;
            }
        }
        mySwap(arr, i, min);
    }
}

int main(void)
{
    std::vector<int> arr = {1, 5, 2, 5, 6, 32, 6, 743, 31, 2};
    selectSort(arr, [](int a, int b)
    {
        return a < b;
    });

    for(int i = 0; i < arr.size(); i++)
    {
        std::cout << arr[i] << " ";
    }
    std::cout << std::endl;

    return 0;
}
```

---
这个实现，就已经将

- 算法逻辑：selectSort负责如何寻找最小元素
- 排序逻辑：Compare负责定义什么叫 “小”
- 交换逻辑：mySwap负责元素交换

三部分分离

## 复杂度分析

假设，要对有 n 个元素的数组 arr 进行排序：

- 外层循环 i 执行 n 次
- 对于每一次 i ，内层循环需要在未排序区间 `[i, n)` 中寻找最小值

内层循环执行次数：

$$ 
(n-1)+(n-2)+...+2+1 
$$

根据等差数列求和：

$$
S=\frac{n(n-1)}{2}
$$

忽略常数系数和低阶项:

$$
O(n^2)
$$

即：

> **时间复杂度为:** $O(n^2)$ 

**注:**

无论数组是否已经有序，每一次循环仍然需要扫描完整的未排序区间寻找最小元素

所以:

**选择排序的时间复杂度和数组的初始状态无关**
