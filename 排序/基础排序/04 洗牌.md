## 前言

在实际应用中，经常需要将一个数组随机打乱，例如：

- 扑克牌洗牌
- 游戏随机生成
- 随机排序

这种操作称为 **shuffle(洗牌)** 

一个好的洗牌算法需要满足：

> 每一种排列出现的概率相同，即保证均匀随机
## 代码(Fisher-Yates算法)

```cpp
#include <iostream>
#include <vector>
#include <random>

template <typename T>
void mySwap(std::vector<T>& arr, int a, int b)
{
    T temp = arr[a];
    arr[a] = arr[b];
    arr[b] = temp;
}

template <typename T>
void shuffle(std::vector<T>& arr, std::mt19937& gen)
{
    int n = arr.size();
    for(int i = 0; i < n; i++)
    {
        std::uniform_int_distribution<int> dis(0, i);
        int r = dis(gen);
        mySwap(arr, r, i);
    }

}

int main(void)
{
    std::random_device rd;
    std::mt19937 gen(rd());
    std::vector<int> arr = {1, 2, 3, 4, 5, 6};

    shuffle(arr, gen);

    for(int i = 0; i < arr.size(); i++)
    {
        std::cout << arr[i] << " ";
    }
    std::cout << std::endl;
    std::cin.get();
    return 0;
}
```

## 错误的洗牌方式

一种常见错误：

```cpp
for(int i = 0; i < n; i++)
{
    int j = random(0, n - 1);
    swap(arr[i], arr[j]);
}
```

表面上：

- 每一步都有随机交换
- 每个位置都有机会变化

但是它不能保证均匀随机

---
**为什么不均匀？** 

假设：

有一个数组 `[1, 2, 3]` 

这个数组一共有

$$
3! = 3 \times 2 \times 1 = 6
$$

种排列

均匀随机要求，每种排列概率相同：

$$
\frac{1}{6}
$$

但是错误算法种：

每一步都从：

$$
[0,n - 1]
$$

中选择位置

因此：

- 不同排列可以通过不同数量的交换过程得到
- 有些排列生成路径更多
- 有些排列生成路径更少

**最终导致，概率不均匀**

## Fisher-Yates算法为什么对

```cpp
for(int i = 0; i < n; i++)
{
	std::uniform_int_distribution<int> dis(0, i);
	int r = dis(gen);
	mySwap(arr, r, i);
}
```

核心思想：

> 每次只在未确定区域中随机选择一个元素，并将它放入当前位置

例如：

随着 i 增大：

```
i = 0
选择范围：[0, 0]

i = 1
选择范围：[0, 1]

i = 2
选择范围：[0, 2]
```

每一步的选择概率，总共有：

$$
1 \times 2 \times 3 \times ... \times n = n!
$$

种选择，

而数组也有：

$$
n!
$$

种排列

因此：

> 每一种排列都有相同数量的生成路径，并且每条路径概率相同，因此最终概率相同
