## 排序思路

插入排序的核心思想：

> 将当前元素插入到已经排好序的部分，使整个区间继续保持有序

在第 i 次迭代中：

- `[0, i)` 是已经排序好的区间
- 将 `arr[i]` 插入到 `[0, i)` 中的正确位置
- 使 `[0, i]` 仍然保持有序

## 循环不变性

**对于插入排序** 

- 在第 i 次迭代开始前，区间 `[0, i)` 已经有序
- 第 i 次迭代后，区间 `[0, i]` 有序

## 代码

```cpp
#include <iostream>
#include <vector>

template <typename T>
void mySwap(std::vector<T>& arr, int i, int j)
{
    T temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
}

template <typename T, typename Compare>
void insertSort(std::vector<T>& arr, Compare cmp)
{
    for(int i = 1; i < arr.size(); i++)
    {
        for(int j = i; j > 0; j--)
        {
            if(cmp(arr[j], arr[j-1]))
            {
                mySwap(arr, j, j - 1);
            }
            else
            {
                break;
            }
        }
    }
}

int main(void)
{
    std::vector<int> arr = {1, 5, 2, 5, 6, 32, 6, 743, 31, 2};
    insertSort(arr, [](int a, int b)
    {
        return a < b;
    });

    for(int i = 0; i < arr.size(); i++)
    {
        std::cout << arr[i] << " ";
    }
    std::cout << std::endl;

    
    return 0;
}
```

## 复杂度分析

### 逆序对(Inversion Pair)

对于升序排序：

> 在数组中，前面的元素比后面的元素大

例：
如果 `i < j` 但是 `arr[i] > arr[j]`

则称：
`(arr[i], arr[j])` 构成一个逆序对

---
### 插入排序与逆序对的关系

插入排序中：

```cpp
if(cmp(arr[j], arr[j-1]))
{
	mySwap(arr, j, j - 1);
}
```
对于升序排序：

只有：

`arr[j-1] > arr[j]`

时才会交换，这说明 `arr[j-1]` 和 `arr[j]` **构成一个逆序对** 

因此：

> **每一次交换都会消除一个逆序对** 

---
### 交换次数 = 逆序对数量

考虑一个元素：

当它在插入排序中向左移动一次时：

说明它与左侧的元素存在一个逆序关系

---
假设：

存在数组 `[2, 5, 8, 3]` 

插入 `3` ：

- 8 > 3： 此时数组为 `[2, 5, 3, 8]` 
- 5 > 3： 此时数组为 `[2, 3, 5, 8]` 

对应两个逆序对：

`(8, 3)`
`(5, 3)` 

所以：

> **一个元素移动的次数，等于它参与的逆序对数量** 

所有元素移动次数之和 = 原数组中的逆序对数量

所以

交换次数 = 逆序对数量

---
### 部分有序数组

定义一个数组，如果其 **逆序对数量** 是：

- 线性
- 比 N 乘以某个常数小

那么我们就称这个数组为 **部分有序数组** 

即：

如果一个数组的逆序对数量较少，称为部分有序数组

**插入排序** 对于部分有序数组，它的运行时间是 **线性的** 

---
### 时间复杂度

设数组中的逆序对数量为 `k` 

插入排序：

- 遍历数组需要 $O(n)$ 
- 每个逆序对对应一次交换

因此：

> **时间复杂度为：** $O(n + k)$ 

---
对于 **部分有序数组** 

如果：

$$
k=O(n)
$$

其中 `k` 为逆序对数量，表示 `k` 的增长速度不会超过 `n` 的常数倍

则：

$$
O(n+k)=O(n)
$$

因此：

> **时间复杂度为：** $O(n)$ 

---
**极端情况** 

假设一个数组是 **完全有序的** ：

`[1, 2, 3, 4, 5]` 

逆序对数量：

$$
k=0
$$

则：

> **时间复杂度为：** $O(n)$ 

---
假设一个数组是 **完全逆序的** ：

`[5, 4, 3, 2, 1]` 

逆序对数量：

$$
k=\frac{n(n-1)}{2}
$$

则：

> **时间复杂度为：** $O(n^2)$
