## 排序思路

**希尔排序(ShellSort)** 是一种基于插入排序改进的排序算法

---
插入排序的主要问题在于：

> 当一个元素需要移动到较远的位置时，插入排序只能通过相邻交换（或移动）逐步前进

例如：

一个较小的元素位于数组末尾，即使它最终应该移动到数组前端，也需要经过大量移动

但是，插入排序有一个重要的性质，是希尔排序高效的基础：

> 当数组已经接近有序时（部分有序），插入排序的效率非常高，时间复杂度接近线性

基于这个性质，希尔排序产生了一个核心思想：

> 先通过一定的方法，使数组逐渐变得接近有序，再利用插入排序完成最终排序

这个过程称为 **h-排序(h-sorting)** 

- 选择一个增量 h
- 将距离为 h 的元素看作一个子序列
- 对这些子序列分别进行插入排序

通过不断缩小 h ，使数组越来越有序

最终：

当 `h = 1` 时，希尔排序退化为一次普通插入排序，由于此时数组已经接近有序，因此能够快速完成排序

## 增量排序的传递性(h-sorting property)

希尔排序的 **重要性质**：

> 如果数组已经是 h-有序 的，那么经过一次 k-排序 后，数组仍然保持 h-有序

---
直观理解：

h-排序 建立的是一种间隔为 h 的有序关系，例如：

- 对所有 i ，满足 `a[i] <= a[i+h]` 

之后进行 k-排序 时，只会调整距离为 k 的元素之间的顺序

由于 k-排序 只会调整距离为 k 的子序列内部的元素，这些调整不会破坏已经建立的 h-有序 关系

因此，希尔排序可以不断缩小增量：

- 大增量负责快速消除大范围的无序
- 小增量负责进一步细化有序性

最终当 `h=1` 时，整个数组完全有序

---
假设：

存在数组 `[1, 8, 2, 9, 3, 10, 4, 11]` 
令  `h = 2` `k = 3` 

数组目前是 2-有序的：

```
1 -> 2 -> 3 -> 4
8 -> 9 -> 10 -> 11
```

进行 3-排序：

```
第一组：
1 -> 9 -> 4
排序后：
1 -> 4 -> 9

第二组：
8 -> 3 -> 11
排序后：
3 -> 8 -> 11

第三组：
2 -> 10
排序后：
2 -> 10

数组为：
[1, 3, 2, 4, 8, 10, 9, 11]
```

检查 2-有序性：

```
1 -> 2 -> 8 -> 9
3 -> 4 -> 10 -> 11
```

虽然 3-排序改变了数组中的元素位置
但之前建立的 2-有序性仍然存在

## 代码

```cpp
#include <iostream>
#include <vector>

template <typename T>
void mySwap(std::vector<T>& arr, int a, int b)
{
    T temp = arr[a];
    arr[a] = arr[b];
    arr[b] = temp;
}

template <typename T, typename Compare>
void shellSort(std::vector<T>& arr, Compare cmp)
{
    int n = arr.size();
    int h = 1;
    while(3 * h + 1 < n) // h < n / 3
    {
        h = 3 * h + 1;
    }
    while(h >= 1)
    {
        for(int i = h; i < n; i++)
        {
            for(int j = i; j >= h && cmp(arr[j], arr[j - h]); j -= h)
            {
                mySwap(arr, j, j - h);
            }
        }
        h = (h - 1) / 3; //h / 3
    }
}

int main(void)
{
    std::vector<int> arr = {1, 5, 2, 5, 6, 32, 6, 743, 31, 2};
    shellSort(arr, [](int a, int b)
    {
        return a < b;
    });

    for(int i = 0; i < arr.size(); i++)
    {
        std::cout << arr[i] << " ";
    }
    std::cout << std::endl;

    return 0;
}
```

---
**h-sort 代码注解** 

```cpp
for(int i = h; i < n; i++)
{
	for(int j = i; j >= h && cmp(arr[j], arr[j - h]); j -= h)
	{
		mySwap(arr, j, j - h);
	}
}
```

希尔排序中的 h-排序，并不会真的创建多个子数组

例如：

h = 3 时，逻辑上的 h-子序列为：

```
index:
0 -> 3 -> 6
1 -> 4 -> 7
2 -> 5 -> 8
```

但是代码中不会显示分组，而是利用下标关系

- 当前待插入元素位置为 i
- j 表示当前元素在 h-序列中的比较位置
- 它在 h-序列中的前一个元素为 j - h

因此：

普通插入排序：
`j--` 

希尔排序：
`j -= h` 

本质上只是改变了寻找前驱元素的方式

---
例如，`h = 3` 

```
index:
0 -> 3 -> 6

当处理 index = 6 时：
j = 6

前一个元素位置为：
j - h = 6 - 3 = 3

如果需要交换，则继续：
j -= h

继续比较 index = 3 和 index = 0
```

因此，内循环本质上就是对 h-子序列执行插入排序

## 复杂度分析

希尔排序的时间复杂度取决于选择的 **增量序列** 

---
对于 **Knuth** 增量序列：

 $$
 h = 1, 4, 13, 40, ... (3h + 1)
 $$

其时间复杂度为：

> **最坏情况：** $O(n^{3/2})$ 
> **最好情况：** $O(n)$
