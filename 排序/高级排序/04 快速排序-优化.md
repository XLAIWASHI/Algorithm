## 优化2-三路快排

### 优化思路

我们之前实现的快速排序，难以处理有多个重复元素的情况；为了解决这个问题，我们可以将区间划分为三个部分：

- `< pivot:` 小于 `pivot` 的元素
- `== pivot:` 等于 `pivot` 的元素
- `> pivot:` 大于 `pivot` 的元素

一次划分，批量处理相同元素

---
### 三路划分

为了实现三路划分，我们使用三个位置：

```
lo  i  hi
```

分别表示：

- `lo:` 小于 `pivot` 区间的左侧边界
- `i:` 当前正在检查的元素
- `hi:` 大于 `pivot` 区间的右侧边界

遍历过程中，根据当前元素与 `pivot` 的关系，将元素放入对应的区域：

---
**1.当前元素 < pivot** 

将当前元素与左边界交换：

$$
swap(first + i, first + lo);
$$

然后：

```
++lo;
++i;
```

---
**2.当前元素 > pivot** 

将当前元素与右边界交换：

$$
swap(first + i, first + hi);
$$

然后：

```
--hi;
```

---
**3.当前元素 == pivot** 

当前元素已经属于中间区域，因此直接：

```
++i;
```

---
### 划分结果

遍历结束后，得到：

```
[first, lo)        < pivot
[lo, hi + 1)      == pivot
[hi + 1, last)     > pivot
```

### 代码

```cpp
template <typename RandomIt, typename Compare>
        std::pair<RandomIt, RandomIt> partition(RandomIt first, RandomIt last, Compare cmp)
        {
            using ValueType = typename std::iterator_traits<RandomIt>::value_type;
            using DifferenceType = typename std::iterator_traits<RandomIt>::difference_type;

            const DifferenceType size = last - first;

            DifferenceType lo = 0;
            DifferenceType hi = size - 1;
            DifferenceType i = lo;

            // 随机选取pivot
            detail::choosePivotRandomly(first, last);
            const ValueType pivot = *first;

            while (i <= hi)
            {
                if (cmp(*(first + i), pivot))
                {
                    xlws::swap(first + i, first + lo);
                    ++lo;
                    ++i;
                }
                else if (cmp(pivot, *(first + i)))
                {
                    xlws::swap(first + i, first + hi);
                    --hi;
                }
                else
                {
                    ++i;
                }
            }
            
            return {first + lo, first + hi + 1};
        }
    }
```
