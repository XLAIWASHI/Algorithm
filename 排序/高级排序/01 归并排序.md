## 排序思路

**分治法** 

> 将一个大问题拆解成一个个小问题，分别解决小问题，最后将结果合并，这种思想叫做 **分治法(Divide and Conquer)** 

归并排序就是利用了 **分治法** 的思想

---
**归并排序思路** 

将一个无序数组不断拆分成更小的子数组，直到每个子数组只有一个元素，然后再将这些有序的小数组逐步合并，最终得到一个完整的有序数组

---
**合并过程** 

合并时，需要将两个 **已经有序的数组** 合并成一个新的有序数组，最终形成一个更大的有序数组

---
## 代码

### 递归实现

```cpp
#pragma once

#include <iterator>
#include <utility>
#include <cstddef>
#include <functional>

namespace xlws
{
    namespace detail
    {
        template <typename RandomIt, typename Compare>
        void merge(RandomIt first, RandomIt mid, RandomIt last, Compare cmp)
        {
            using ValueType = typename std::iterator_traits<RandomIt>::value_type;
            // using 等价于 typedef 目的是在当前作用域内创建一个新名字
            // typename 显式类型指示器，把后面的名字当作一个类型来处理
            // std::iterator_traits<RandomIt> 标准模板类（类型萃取器），接受迭代器类型 RandomIt ,
            // "询问" 该迭代器的各种属性
            // value_type 是 iterator_traits 内部定义的一个嵌套类型，表示该迭代器指向的元素的类型
            const auto leftSize = mid - first;
            const auto rightSize = last - mid;

            ValueType* temp = new ValueType[leftSize + rightSize];

            RandomIt left = first; // 创建一个迭代器 left，让它从原地址的第一个元素开始遍历
            RandomIt right = mid;

            std::size_t index = 0;

            while(left != mid && right != last)
            {
                if(cmp(*right, *left))
                {
                    temp[index++] = *right++;
                }
                else
                {
                    temp[index++] = *left++;
                }
            }
            // 单侧提前走完
            while(left != mid)
            {
                temp[index++] = *left++;
            }
            while(right != last)
            {
                temp[index++] = *right++;
            }
            // 移动回原地址
            for(std::size_t i = 0; i < index; ++i)
            {
                *(first + i) = std::move(temp[i]);
            }

            delete[] temp;
        }
    }

    template <typename RandomIt, typename Compare>
    void mergeSort(RandomIt first, RandomIt last, Compare cmp)
    {
        const auto distance = last - first;

        if(distance <= 1)
            return;
        
        RandomIt mid = first + distance / 2;

        // 将区间 [first, last) 分成 [first, mid) 和 [mid, last)
        mergeSort(first, mid, cmp);
        mergeSort(mid, last, cmp);

        detail::merge(first, mid, last, cmp);
    }

    template <typename RandomIt>
    void mergeSort(RandomIt first, RandomIt last)
    {
        mergeSort(first, last, std::less<>{});
        //less 小于比较器
    }
}
```

### 自下而上实现

**简单说明** 

- 将未排序数组的每一个元素视为已排序的序列，该长度为 1
- 遍历合并一对长度为 1 的子序列，成为一组长度为 2 的子序列
- 然后对长度为 2 的子序列合并再排序
- 以此类推

---
```cpp
#include <iostream>
#include <iterator>
#include <utility>
#include <cstddef>
#include <functional>

template <typename RandomIt, typename Compare>
void merge(RandomIt first, RandomIt mid, RandomIt last, Compare cmp)
{
    using ValueType = typename std::iterator_traits<RandomIt>::value_type;

    const auto leftSize = mid - first;
    const auto rightSize = last - mid;

    ValueType* temp = new ValueType[leftSize + rightSize];

    RandomIt left = first;
    RandomIt right = mid;

    std::size_t index = 0;

    while(left != mid && right != last)
    {
        if(cmp(*right, *left))
        {
            temp[index++] = *right++;
        }
        else
        {
            temp[index++] = *left++;
        }
    }

    while(left != mid)
    {
        temp[index++] = *left++;
    }
    while(right != last)
    {
        temp[index++] = *right++;
    }

    for(std::size_t i = 0; i < index; ++i)
    {
        *(first + i) = std::move(temp[i]);
    }

    delete[] temp;
}

template <typename RandomIt, typename Compare>
void mergeSort(RandomIt first, RandomIt last, Compare cmp)
{
    using DifferenceType = typename std::iterator_traits<RandomIt>::difference_type;

    const DifferenceType distance = last - first;

    for(DifferenceType sz = 1; sz < distance; sz *= 2)
    {
        for(DifferenceType lo = 0; lo < distance - sz; lo += sz * 2)
        {
            const DifferenceType mid = lo + sz;
            const DifferenceType mergeLast = std::min(lo + sz * 2, distance);
            merge(first + lo, first + mid, first + mergeLast, cmp);
        }
    }
}

template <typename RandomIt>
void mergeSort(RandomIt first, RandomIt last)
{
    mergeSort(first, last, std::less<>{});
}

int main(void)
{
    int arr[] = {3, 1, 5, 6, 4};

    mergeSort(arr, arr + 5);

    for(int x : arr)
    {
        std::cout << x << " ";
    }
    std::cout << std::endl;

    return 0;
}
```

## 复杂度分析

**时间复杂度** 

归并排序每次都会把数组分成两半

假设数组有 n 个元素，n 为 2 的幂数：

```
第一层： n

第二层： n/2 + n/2

第三层： n/4 + n/4 + n/4 + n/4
```
虽然每一层被拆成了越来越多的小数组，但是这一层所有元素加起来仍然是 n 个

而每一层的合并操作，都需要遍历这一层的所有元素，因此：

> **每一层的合并：** $O(n)$ 

---
**一共有多少层** 

每次都除以 2：

```
n
n/2
n/4
n/8
...
1
```

假设一共拆了 k 次

所以：

$$
2^k = n
$$
$$
k = \log_2n
$$

因此：

> **时间复杂度为：** $O(nlogn)$ 
> **空间复杂度为：** $O(n)$
