## 排序思路

快速排序是一种 **分治算法(Divide and Conquer)** 

---
**核心思想** 

- 选择一个 **基准元素(pivot)** ，通过 **partition** 操作，将数组划分为两个部分
- 左边元素都 **不大于** pivot
- 右边元素都 **不小于** pivot
- 然后递归地对左右两个子数组进行排序

---
## 和归并排序的区别

**归并排序** 

> 先递归，再处理

---
**快速排序** 

> 先处理，再递归

---
## partition

**核心目标** 

将 pivot 送到正确的位置

**满足：**

- 左边 <= pivot
- 右边 >= pivot

**partition结束后：** 

- pivot 处于最终位置
- 左侧元素不大于 pivot
- 右侧元素不小于 pivot

---
**双指针(Hoare partition)** 

维护两个指针：

```
i 从左向右移动
j 从右向左移动
```

```
i 和 j 找到的元素都是 “不符合当前区域要求” 的元素

i指针寻找 >= pivot的元素
说明这个元素不应该出现在左侧

j指针寻找 <= pivot的元素
说明这个元素不应该出现在右侧

交换后，两个元素回到正确区域
```

---
**循环不变性** 

每次循环：

- `a[lo ... i-1] <= pivot` i左侧已经完成划分
- `a[j+1 ... hi] >= pivot` j右侧已经完成划分
- `a[i ... j]` 是尚未处理区域
