## 排序思路

快速排序是一种 **分治算法(Divide and Conquer)** 

---
**核心思想** 

- 选择一个 **基准元素(pivot)** ，通过 **partition** 操作，将数组划分为两个部分
- 左边元素都 **不大于** pivot
- 右边元素都 **不小于** pivot
- 然后递归地对左右两个子数组进行排序

---
## 和归并排序的区别

**归并排序** 

> 先递归，再处理

---
**快速排序** 

> 先处理，再递归

---
## partition

**核心目标** 

将 pivot 送到正确的位置

**满足：**

- 左边 <= pivot
- 右边 >= pivot

---
**双指针partition** 

维护两个指针：

```
i 从左向右移动
j 从右向左移动
```

```
i指针寻找 >= pivot的元素
找到后，停止向右

j指针寻找 <= pivot的元素
找到后，停止向左

此时，交换 i 和 j所指向的元素
继续寻找
```

---
**循环不变性** 

每次循环：

- i 左边的元素都 <= pivot
- j 右边的元素都 >= pivot
