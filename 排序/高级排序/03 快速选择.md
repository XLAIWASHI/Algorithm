## 介绍

QuickSelect 用于寻找一个序列中第 `k` 小（或第 `k` 大）的元素

它和快速排序使用类似的 `partition` 思想，但不同的是：

- **快速排序：** 左右两边都继续处理
- **QuickSelect：** 只继续处理 `k` 所在的一边

## 思路

通过 `partition` 将数组分割，根据 `pivot` 最终所在的下标与 `k` 进行比较：

- `pivot` 下标 `< k` ：第 `k` 个元素在右侧，继续处理右侧
- `pivot` 下标 `> k` ：第 `k` 个元素在左侧，继续处理左侧
- `pivot` 下标 `== k` ：找到第 `k` 个元素

## 代码

```cpp
#pragma once

#include <iterator>
#include <functional>
#include "XLWS_DS/utility/Swap.hpp"

namespace xlws
{
    namespace detail
    {
        template <typename RandomIt, typename Compare>
        RandomIt partition(RandomIt first, RandomIt last, Compare cmp)
        {
            using ValueType = typename std::iterator_traits<RandomIt>::value_type;
            using DifferenceType = typename std::iterator_traits<RandomIt>::difference_type;

            const DifferenceType size = last - first;

            DifferenceType lo = 0;
            DifferenceType hi = size - 1;

            const ValueType pivot = *first;

            while (true)
            {
                while (lo < hi && cmp(*(first + lo + 1), pivot))
                {
                    ++lo;
                }

                while (lo < hi && cmp(pivot, *(first + hi)))
                {
                    --hi;
                }

                if (lo >= hi)
                {
                    break;
                }

                xlws::swap(first + lo + 1, first + hi);
                ++lo;
                --hi;
            }
            xlws::swap(first, first + hi);
            return first + hi;
        }
    }

    template <typename RandomIt, typename Compare>
    RandomIt quickSelect(RandomIt first, RandomIt last,
        typename std::iterator_traits<RandomIt>::difference_type k, Compare cmp)
    {
        using DifferenceType = typename std::iterator_traits<RandomIt>::difference_type;
        DifferenceType lo = 0, hi = (last - first) - 1;

        while (lo < hi)
        {
            RandomIt split = detail::partition(first + lo, first + hi + 1, cmp);
            DifferenceType j = split - first;
            
            if (j < k)
            {
                lo = j + 1;
            }
            else if (j > k)
            {
                hi = j - 1;
            }
            else
            {
                return first + j;
            }
        }
        return first + lo;
    }

    template <typename RandomIt>
    RandomIt quickSelect(RandomIt first, RandomIt last,
        typename std::iterator_traits<RandomIt>::difference_type k)
    {
        return quickSelect(first, last, k, std::less<>{});
    }
}
```

## 复杂度分析

`partition` 每次需要遍历当前区间，因此一次 `partition` 的时间复杂度为：

```text
O(n)
```

其中 `n` 是当前需要处理的区间大小。

### 最好情况

每次 `pivot` 都能将区间大致分成两半：

```text
N → N/2 → N/4 → N/8 → ...
```

因此：

> **最好情况：** $O(N)$
### 平均情况

平均情况下，QuickSelect 每次能够有效缩小搜索范围，总体平均时间复杂度为：

> **平均情况：** $O(N)$ 

### 最坏情况

如果每次选择的 `pivot` 都很差，例如每次只能排除一个元素：

```text
N → N-1 → N-2 → N-3 → ...
```

需要进行接近 `N` 次 `partition`：

```text
N + (N-1) + (N-2) + ... + 1
```

因此：

> **最坏情况：** $O(N^2)$
