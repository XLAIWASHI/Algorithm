## 优化1-随机选择pivot

### 优化思路

如果元素已经有序，那么每次拿第一个元素作为 `pivot` 会导致划分极度不平衡，使时间复杂度退化为 $O(n^2)$ 

为了解决这个问题，我们可以在 `[first, last)` 区间内，随机选取一个元素作为 `pivot` 

为了不改变原有的划分逻辑，可以将随机选取的元素交换到 `first` ，然后继续使用 `*first` 作为 `pivot` 

---
### 代码

```cpp
template <typename RandomIt>
        void choosePivotRandomly(RandomIt first, RandomIt last)
        {
            using DifferenceType = typename std::iterator_traits<RandomIt>::difference_type;
            
            static std::mt19937 gen(std::random_device{}());

            std::uniform_int_distribution<DifferenceType> dist(0, last - first - 1);

            RandomIt pivot = first + dist(gen);

            xlws::swap(first, pivot);
        }
```

## 优化2-三路快排

### 优化思路

我们之前实现的快速排序，难以处理有多个重复元素的情况；为了解决这个问题，我们可以将区间划分为三个部分：

- `< pivot:` 小于 `pivot` 的元素
- `== pivot:` 等于 `pivot` 的元素
- `> pivot:` 大于 `pivot` 的元素

一次划分，批量处理相同元素

---
### 三路划分

为了实现三路划分，我们使用三个位置：

```
lo  i  hi
```

分别表示：

- `lo:` 小于 `pivot` 区间的左侧边界
- `i:` 当前正在检查的元素
- `hi:` 大于 `pivot` 区间的右侧边界

遍历过程中，根据当前元素与 `pivot` 的关系，将元素放入对应的区域：

---
**1.当前元素 < pivot** 

将当前元素与左边界交换：

$$
swap(first + i, first + lo);
$$

然后：

```
++lo;
++i;
```

---
**2.当前元素 > pivot** 

将当前元素与右边界交换：

$$
swap(first + i, first + hi);
$$

然后：

```
--hi;
```

---
**3.当前元素 == pivot** 

当前元素已经属于中间区域，因此直接：

```
++i;
```

---
### 划分结果

遍历结束后，得到：

```
[first, lo)        < pivot
[lo, hi + 1)      == pivot
[hi + 1, last)     > pivot
```

### 代码

```cpp
template <typename RandomIt, typename Compare>
        std::pair<RandomIt, RandomIt> partition(RandomIt first, RandomIt last, Compare cmp)
        {
            using ValueType = typename std::iterator_traits<RandomIt>::value_type;
            using DifferenceType = typename std::iterator_traits<RandomIt>::difference_type;

            const DifferenceType size = last - first;

            DifferenceType lo = 0;
            DifferenceType hi = size - 1;
            DifferenceType i = lo;

            // 随机选取pivot
            detail::choosePivotRandomly(first, last);
            const ValueType pivot = *first;

            while (i <= hi)
            {
                if (cmp(*(first + i), pivot))
                {
                    xlws::swap(first + i, first + lo);
                    ++lo;
                    ++i;
                }
                else if (cmp(pivot, *(first + i)))
                {
                    xlws::swap(first + i, first + hi);
                    --hi;
                }
                else
                {
                    ++i;
                }
            }
            
            return {first + lo, first + hi + 1};
        }
    }
```

## 优化3-小边递归，大边循环

### 优化思路

之前的快速排序会对左右两个区间都进行递归：

```
quickSort(first, middleFirst, cmp);
quickSort(middleLast, last, cmp);
```

当划分不平衡时，较大的区间也会继续递归，可能导致递归深度增加

因此，我们可以：

> 只递归处理较小的区间，较大的区间通过循环继续处理

这样可以减少递归调用的层数

---
**实现思路** 

- 首先计算左右两个区间的大小
- 比较两个区间的大小
- 小区间递归，大区间修改边界后继续留在当前函数中处理
- 处理完后，不继续递归另一边，而是修改当前的区间
- 如果左边较小，修改 `first = middleLast` 
- 如果右边较小，修改 `last = middleFirst` 

---
**二者区别** 

传统写法：

```
小边 -> 递归
大边 -> 递归
```

小边调用完后，调用大边；但是，大边可能非常大，递归可能持续沿着大边向下延伸

优化后：

```
小边 -> 递归
大边 -> 修改区间 -> while 循环继续处理
```

小边递归返回后，修改当前区间，让 `while` 继续处理大边；大边再次划分后，再递归它产生的新小边

也就是说，我们把直接调用大边这个过程给 **优化** 掉了

---
### 代码

```cpp
template <typename RandomIt, typename Compare>
    void quickSort(RandomIt first, RandomIt last, Compare cmp)
    {
        while (last - first > 1)
        {
            const auto result = detail::partition(first, last, cmp);

            const RandomIt middleFirst = result.first;
            const RandomIt middleLast = result.second;

            const auto leftSize = middleFirst - first;
            const auto rightSize = last - middleLast;

            if (leftSize < rightSize)
            {
                // 左边小：递归处理左边
                quickSort(first, middleFirst, cmp);
                first = middleLast;
            }
            else
            {
                // 右边小：递归处理右边
                quickSort(middleLast, last, cmp);
                last = middleFirst;
            }
        }
    }
```

#pragma once

#include <iterator>
#include <functional>
#include <utility>
#include <random>
#include "XLWS_DS/utility/Swap.hpp"

namespace xlws
{
    namespace detail
    {
        template <typename RandomIt>
        void choosePivotRandomly(RandomIt first, RandomIt last)
        {
            using DifferenceType = typename std::iterator_traits<RandomIt>::difference_type;
            
            static std::mt19937 gen(std::random_device{}());

            std::uniform_int_distribution<DifferenceType> dist(0, last - first - 1);

            RandomIt pivot = first + dist(gen);

            xlws::swap(first, pivot);
        }

        template <typename RandomIt, typename Compare>
        std::pair<RandomIt, RandomIt> partition(RandomIt first, RandomIt last, Compare cmp)
        {
            using ValueType = typename std::iterator_traits<RandomIt>::value_type;
            using DifferenceType = typename std::iterator_traits<RandomIt>::difference_type;

            const DifferenceType size = last - first;

            DifferenceType lo = 0;
            DifferenceType hi = size - 1;
            DifferenceType i = lo;

            // 随机选取pivot
            detail::choosePivotRandomly(first, last);
            const ValueType pivot = *first;

            while (i <= hi)
            {
                if (cmp(*(first + i), pivot))
                {
                    xlws::swap(first + i, first + lo);
                    ++lo;
                    ++i;
                }
                else if (cmp(pivot, *(first + i)))
                {
                    xlws::swap(first + i, first + hi);
                    --hi;
                }
                else
                {
                    ++i;
                }
            }
            
            return {first + lo, first + hi + 1};
        }
    }

    template <typename RandomIt, typename Compare>
    void quickSort(RandomIt first, RandomIt last, Compare cmp)
    {
        while (last - first > 1)
        {
            const auto result = detail::partition(first, last, cmp);

            const RandomIt middleFirst = result.first;
            const RandomIt middleLast = result.second;

            const auto leftSize = middleFirst - first;
            const auto rightSize = last - middleLast;

            if (leftSize < rightSize)
            {
                // 左边小：递归处理左边
                quickSort(first, middleFirst, cmp);
                first = middleLast;
            }
            else
            {
                // 右边小：递归处理右边
                quickSort(middleLast, last, cmp);
                last = middleFirst;
            }
        }
    }

    template <typename RandomIt>
    void quickSort(RandomIt first, RandomIt last)
    {
        quickSort(first, last, std::less<>{});
    }
}
